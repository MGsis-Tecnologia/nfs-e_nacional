# Código de Tributação Municipal

## ❓ O que é?

O **Código de Tributação Municipal** é um código numérico usado pela Prefeitura de Foz do Iguaçu para identificar e classificar o tipo de serviço prestado para fins de tributação do ISS (Imposto sobre Serviços).

Cada tipo de serviço tem seu próprio código de tributação, que varia de acordo com:
- A natureza do serviço prestado
- A aplicação de dedução ou desconto
- A faixa de valor
- Outras características específicas

---

## 📋 Exemplos de Códigos Comuns

| Código | Descrição | Exemplo |
|--------|-----------|---------|
| **01** | Serviços de Informática | Desenvolvimento de software |
| **02** | Consultoria | Consultoria empresarial |
| **03** | Manutenção e Reparos | Manutenção de equipamentos |
| **04** | Educação | Cursos e treinamentos |
| **05** | Saúde | Serviços médicos |
| **06** | Publicidade | Serviços de publicidade |
| **07** | Hospedagem | Serviços de hospedagem |

⚠️ **Estes são apenas exemplos!** Os códigos específicos para Foz do Iguaçu podem ser diferentes.

---

## 🔍 Como Encontrar o Código Correto

### Opção 1: Portal da Prefeitura de Foz do Iguaçu
1. Acesse: [https://fozdoiguacu.pr.gov.br](https://fozdoiguacu.pr.gov.br)
2. Procure por "Tabela de Códigos de Tributação"
3. Ou "Classificação de Serviços ISS"
4. Encontre o seu tipo de serviço na lista

### Opção 2: Sistema GestãoISS
1. Acesse: [https://fozdoiguacupr.gestaoiss.com.br](https://fozdoiguacupr.gestaoiss.com.br)
2. Faça login com sua conta
3. Vá para "Consultas" ou "Tabelas"
4. Procure por "Códigos de Tributação Municipal"

### Opção 3: Contato Direto
- **Telefone:** Prefeitura de Foz do Iguaçu
- **Email:** Departamento de Tributos
- **Pessoalmente:** Secretaria Municipal de Finanças

### Opção 4: Seu RPS Anterior
Se você já emitiu RPS antes, verifique qual código foi usado:
1. Abra seu sistema anterior ou arquivo de RPS
2. Verifique o código de tributação que consta lá
3. Use o mesmo código para RPS similares

---

## 💡 Dicas Importantes

### ✅ Para Preenchimento Correto

1. **Confira o código antes de salvar**
   - Não deixe em branco
   - Verificar com a prefeitura em caso de dúvida

2. **Use o código mais específico**
   - Se há múltiplos códigos que se aplicam, escolha o mais específico para seu serviço

3. **Mantenha a consistência**
   - RPS similares devem usar o mesmo código
   - Se mudar de código, documente o motivo

4. **Exemplo prático**
   - **Serviço:** Desenvolvimento de aplicativo web
   - **Item Lista:** 01.07 (Suporte Técnico em Informática)
   - **Código Tributação:** 01 (Serviços de Informática)

---

## ⚠️ O que NÃO fazer

- ❌ Deixar em branco
- ❌ Usar código aleatório
- ❌ Usar código de outro tipo de serviço
- ❌ Usar código de outro município

---

## 📞 Suporte Técnico

Se receber erro durante o envio que mencione "Código de Tributação":

1. **Verifique se está preenchido** nas Configurações do RPS
2. **Confirme com a prefeitura** se o código está correto
3. **Tente código alternativo** se estiver entre dois similares
4. **Contate a prefeitura** se persistir o erro

3. ✅ Tente enviar novamente
